# Задание 5. MVP Roadmap и решения Build / Buy / Partner

План запуска 15.10 в рамках $5 000/мес и шести контракторов. Из 29 функций списка PM в MVP входят 9, и 7 из них в урезанном виде. Остальные разнесены на 6 и 12 месяцев по критериям K1–K3, две отклонены из-за лицензий. Свою логистику и прямые платежи CTO оценены расчётом: логистика отложена до Года 2, где она начинает окупаться; прямой приём платежей без лицензии невозможен, тонкая маршрутизация принята.
