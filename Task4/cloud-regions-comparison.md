# Сравнение облачных регионов — Africa Delivery

Источники: «Вводная» (любой провайдер, катастрофоустойчивость), арт. 3 (локализация), арт. 6 (лимит $5 000/мес, оплата по счёту, без обязательств), [ADR-001](../task2/adr-001-architecture-style.md), [data-residency-map.md](data-residency-map.md). Публичные данные провайдеров — по состоянию на август 2026, ссылки внизу.

Ни у AWS, ни у Google, ни у Microsoft нет региона в Нигерии или Кении: ближайшие — в ЮАР. Регион Oracle в Найроби объявлен, но не запущен, у AWS в Найроби Local Zone только анонсирована. Поэтому сравнение отвечает на два вопроса: где размещается центральный контур без ПДн и кто держит страновые ячейки NG и KE.

## Сравнение

| Провайдер / регион | Доступные сервисы для OPT-A | Задержка до Лагоса / Найроби | Цена (наш центральный контур, Год 1) | SLA | Вывод |
|---|---|---|---|---|---|
| **AWS af-south-1 (Кейптаун)** | 3 зоны доступности; EKS, RDS PostgreSQL Multi-AZ, ElastiCache Redis, S3, KMS; CloudFront с edge-узлами в Лагосе и Найроби | ≈100–150 мс / ≈70–90 мс (Кейптаун на ≈20 мс дальше Йоханнесбурга) | ≈$2 250/мес; регион в среднем на ≈20% дороже us-east-1 | EC2 в ≥2 зонах — 99,99%; RDS Multi-AZ — 99,95%; EKS — 99,95% | **Выбран для центрального контура.** Полный набор managed-сервисов, есть в TCO (A-16), счёт через локального реселлера закрывает требование оплаты по счёту (арт. 6, п. 4) |
| **Google Cloud africa-south1 (Йоханнесбург)** | 3 зоны; GKE, Cloud SQL PostgreSQL, Memorystore, Cloud Storage, Cloud KMS | ≈90–140 мс / ≈51–70 мс | Сопоставимо с AWS, ±10% | Compute в ≥2 зонах — 99,99%; Cloud SQL HA — 99,95%; региональный GKE — 99,95% | Альтернатива. Ближе к Найроби, но платёж по счёту требует отдельного одобрения, а TCO построен на AWS. Задержка для нас некритична: данные субъектов живут в ячейках |
| **Azure South Africa North (Йоханнесбург)** | Зоны доступности; AKS, Azure Database for PostgreSQL Flexible Server с зонной HA, Azure Cache for Redis, Blob Storage, Key Vault | ≈90–140 мс / ≈51–70 мс | Сопоставимо с AWS, ±10% | VM в ≥2 зонах — 99,99%; PostgreSQL Flexible с зонной HA — 99,99%; AKS Standard — 99,95% | **Резервная площадка центрального контура (DR) и цель учения по выходу (LB-05).** Другой провайдер — защита от блокировки аккаунта; счёт через CSP-партнёра |
| **Локальный нигерийский провайдер (шорт-лист: Layer3, провайдеры в Rack Centre, Лагос)** | VM, Kubernetes, managed БД, S3-совместимое хранилище, резервное копирование и DR как сервис (Layer3) | 2–20 мс внутри Нигерии / ≈90–150 мс | Ячейка NG ≈$900/мес (оценка до коммерческого предложения) | Заявлено 99,99% (Layer3); фиксируется в договоре | **Единственный вариант для ячейки NG.** Зрелость managed-сервисов ниже, поэтому: второй ЦОД или второй провайдер в стране для DR, учения по отказу |
| **Локальный кенийский провайдер (шорт-лист: Servercore в iColo NBO1, GEWAPE в iXAfrica NBOX1)** | Managed Kubernetes и БД, S3-совместимое хранилище; у GEWAPE — 2 зоны доступности | ≈90–150 мс / 2–10 мс | Ячейка KE ≈$700/мес (оценка до коммерческого предложения) | По договору, требуем ≥ 99,9% | **Ячейка KE.** Один провайдер — основной, второй — DR, в разных ЦОД Найроби |

## Итог

| Контур | Площадка | Резерв |
|---|---|---|
| Центральный (каталог, изображения, агрегаты, бэк-офис каталога) | AWS af-south-1 | Azure South Africa North: копии без ПДн, warm standby с 7-го месяца |
| Ячейка NG (учётные записи, заказы, платежи, согласия) | Локальный провайдер, Лагос | Второй ЦОД или второй провайдер в Нигерии |
| Ячейка KE | Локальный провайдер, Найроби | Второй провайдер в другом ЦОД Найроби |
| Ячейка ZA (после пилота) | AWS af-south-1, отдельный аккаунт | Azure South Africa North (тоже ЮАР) |

Месячный счёт (облако и SaaS) по оценке: центральный контур $2 250 + Redis $80 + ячейка NG $900 + ячейка KE $700 + SaaS $600 = **$4 530 из $5 000**. Совпадает с [ADR-002](../task3/adr-002-caching-strategy.md). Каждая позиция дороже $500/мес согласуется с CFO заранее, с коммерческим предложением и альтернативой (арт. 6, п. 2): шорт-листы выше и есть эти альтернативы. RFP по ячейкам — до 05.09, замер задержек с RIPE Atlas из Лагоса и Найроби — тогда же.

## Assumptions

- A-16. Цены облака — оценки порядка величины для африканского региона.
- A-25. Задержка Лагос — Йоханнесбург 90–140 мс, Лагос — Кейптаун 100–150 мс (часть маршрутов идёт через Европу; минимум Лиссабон — Лагос — 70 мс). Задержка Найроби — Йоханнесбург — от 51 мс. Подтверждается замером до 05.09.
- A-26. Стоимость: центральный контур ≈$2 250/мес, ячейка NG ≈$900, ячейка KE ≈$700 — до коммерческих предложений.
- A-27. Провайдеры ячеек выбираются по RFP до 05.09 из шорт-листов выше. Обязательные условия: managed PostgreSQL или Kubernetes, оплата по счёту, SLA в договоре, площадки в стране.
