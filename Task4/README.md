# Задание 4. Регуляторные ограничения и стратегия данных

Требований юристов ещё нет, а запуск 15.10. Принято консервативное допущение: всё, что связано с субъектом, включая псевдонимизированные заказы и платежи, хранится и обрабатывается в стране субъекта. Каждая страна — ячейка того же монолита у локального провайдера, центральный контур в AWS af-south-1 хранит только данные без ПДн. Ответ юриста отрабатывается сменой конфигурации и переносом данных, без переписывания кода.
