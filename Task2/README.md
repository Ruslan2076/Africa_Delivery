# Задание 2. Architecture Vision и выбор архитектурного стиля

Три варианта архитектуры посчитаны по одной модели TCO на 5 лет с учётом ФОТ. Выбран модульный монолит на Go с поэтапным наращиванием доступности; позиция CTO разобрана по пунктам с цифрами; отложенные решения привязаны к триггерам.

## Сквозная нумерация

OPT — варианты, CTO — пункты предложения CTO, LB — отложенные решения, UC — сценарии, P — принципы, NFR — нефункциональные требования. G, D, CN, R, A, STK, C, Q продолжают нумерацию задания 1.
