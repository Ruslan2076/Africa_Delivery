# Реестр противоречий — Africa Delivery

Источники: арт. 1–8 входных материалов; «Вводная» — описание компании, рынка и целей бизнеса; Шаблон 1 — модель TCO, Шаблон 3 — Data Residency Map. Стейкхолдеры (STK-xx) — см. `stakeholder-matrix.md`, допущения (A-xx) — `architecture-canvas.md`.

## Что физически невозможно одновременно

1. Доступность 99,99% с active-active в нескольких регионах и ёмкостью под 10 млн пользователей **и** потолок $5 000/мес на всё техническое (C-01).
2. 40–50 сервисов, Istio, собственные Kafka и БД в трёх кластерах **и** шесть контракторов при сроке 8 недель (C-02).
3. Прямой приём платежей через M-Pesa и Flutterwave **и** запуск 15.10 без собственной платёжной лицензии (C-04).
4. Персональные данные нигерийцев в Нигерии **и** размещение только в регионах публичных облаков из Data Residency Map, где нет площадки ни в Нигерии, ни в Кении (C-05).

## Что не является требованием

| Утверждение (источник) | Почему не требование | Как трактуем |
|---|---|---|
| «Как Amazon» (арт. 1), «как Wildberries» (арт. 7) | Аналогия без состава и метрик | Целевой состав задаёт MVP во Вводной |
| «Всё P0» (арт. 4, заметки) | Автор уволился; инвестор: «забудь про него», «бэк-офис подождёт», блокчейн «не к октябрю» (арт. 1) | Список — бэклог идей без приоритета |
| «Лицензии — не твоя забота» (арт. 1) | Не отменяет требования лицензии (арт. 3, п. 4) | Архитектура исходит из партнёрской модели |
| «$12 000 за минуту простоя» (арт. 1, арт. 7) | Оценка для распродажи; в пересчёте на сутки это $17,3 млн выручки, несовместимо с пилотом на 100 продавцов (Вводная) | Цена минуты в пиковые окна распродаж (A-02) |
| «10 млн пользователей с первого дня» (арт. 5) | Предпочтение CTO; бизнес-цель — 1 млн+ за год (Вводная), CFO просит цену ошибки в обе стороны (арт. 6) | Сценарий стресс-теста TCO, не основа сайзинга (A-01) |
| «Сертификация CNCF» (арт. 5, Вводная) | Программа CNCF сертифицирует конформность Kubernetes-платформ, а не прикладные системы | Платформа работает на conformant Kubernetes и не зависит от проприетарных API провайдера |
| Блокчейн-лояльность (арт. 4, п. 14; арт. 5) | «Изучите. Не к октябрю» (арт. 1) | Исследовательская задача в Architecture Vision, вне MVP |
| «Бо́льшая часть — выходные за написанием YAML» (арт. 5) | Оценка трудозатрат без расчёта | Не используется при планировании |

## Assumptions

- A-01. Сайзинг: пик первой недели — 50 тыс. одновременных сессий (ориентир арт. 2, п. 7), годовой масштаб — 1 млн пользователей (Вводная); 10 млн — стресс-сценарий TCO.
- A-02. $12 000/мин — стоимость простоя в окнах распродаж; вне их стоимость минуты считается от фактического GMV.
- A-03. До заключения юриста действует строгая трактовка: все ПДн субъекта хранятся в стране субъекта.
