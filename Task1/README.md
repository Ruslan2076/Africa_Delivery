# Задание 1. Карта стейкхолдеров и Architecture Canvas

Анализ входных материалов до встречи в Найроби: кто принимает решения, какие требования несовместимы, что не является требованием и какие допущения приняты, чтобы двигаться дальше.

## Файлы

| Файл | Описание |
|---|---|
| `stakeholder-matrix.md` | Кто решает по каждой области (закон, дата, деньги, скоуп, технологии) и правило эскалации. Матрица из 12 стейкхолдеров (STK-01–STK-12): интересы, влияние, интерес, приоритет при конфликте, способ коммуникации |
| `stakeholder-influence-interest.puml` | Исходник диаграммы «Влияние / Интерес» в PlantUML |
| `stakeholder-influence-interest.png` | Отрендеренная диаграмма: распределение стейкхолдеров по квадрантам «Управлять плотно / Удовлетворять / Информировать / Наблюдать» |
| `contradictions.md` | Четыре требования, невыполнимые одновременно; реестр из 10 противоречий между артефактами (C-01–C-10) с обеими сторонами, риском, владельцем решения и рекомендацией; таблица утверждений, которые не являются требованиями |
| `architecture-canvas.md` | Architecture Canvas: цели (G-xx), ключевые драйверы (D-xx), ограничения (CN-xx), риски с мерами и метриками (R-xx), полный список допущений (A-xx) |
| `open-questions.md` | Пять вопросов участникам встречи (Q-01–Q-05): кому, какое решение блокирует, дедлайн ответа и допущение, если ответа не будет |

## Сквозная нумерация

STK — стейкхолдеры, C — противоречия, Q — вопросы, G — цели, D — драйверы, CN — ограничения, R — риски, A — допущения. Идентификаторы одинаковы во всех файлах задания.
