# Quality Attribute Scenarios — Africa Delivery

Каждый сценарий описан шестью полями: источник стимула, стимул, артефакт, окружение, отклик, мера отклика. Мера отклика проверяется тестом или метрикой из [nfr-registry.md](nfr-registry.md) и [observability.md](observability.md).

## QAS-01. Доступность: отказ зоны с основной БД

| Поле | Значение |
|---|---|
| Источник стимула | Инфраструктура облачного провайдера |
| Стимул | Зона доступности с основным экземпляром PostgreSQL перестаёт отвечать |
| Артефакт | Модули заказа и оплаты, managed PostgreSQL (3 зоны) |
| Окружение | Штатная работа, вечерний пик, идёт флеш-распродажа |
| Отклик | Managed PostgreSQL переключается на синхронную реплику в другой зоне. Приложение переподключается с Retry и экспоненциальной задержкой. Каталог продолжает отдаваться из CDN и Redis. Покупатель на шаге оплаты видит «повторите через минуту», а не ошибку |
| Мера отклика | Оформление заказа недоступно ≤ 2 мин; 0 потерянных подтверждённых платежей (RPO 0); доступность каталога 100%; расход бюджета SLI-PAY-01 ≤ 5% (NFR-06) |

## QAS-02. Доступность: отказ платёжного партнёра

| Поле | Значение |
|---|---|
| Источник стимула | M-Pesa API (внешний партнёр) |
| Стимул | 50% запросов на инициирование платежа завершаются таймаутом 10 с |
| Артефакт | Модуль оплаты, адаптер M-Pesa |
| Окружение | Штатная работа в Кении, обычная нагрузка |
| Отклик | Circuit Breaker адаптера открывается после 5 ошибок из 20 запросов за 30 с. Покупателю сразу предлагается оплата через Flutterwave, заказ хранится в статусе «ожидает оплаты». Каждые 60 с пробный запрос проверяет восстановление партнёра. Дежурный получает алерт |
| Мера отклика | Переключение ≤ 30 с; ≥ 99% попыток оплаты получают альтернативу или финальный ответ; алерт ≤ 2 мин (NFR-11) |

## QAS-03. Задержка P99: пик каталога в неделю запуска

| Поле | Значение |
|---|---|
| Источник стимула | 50 тыс. одновременных покупателей после радиоролика и стрима 17.10 |
| Стимул | 10 000 запросов в секунду на каталог и карточки |
| Артефакт | CDN, роль монолита «каталог», Redis, реплика чтения PostgreSQL |
| Окружение | Пиковая нагрузка, 3G/LTE с обрывами, кеш прогрет за 30 мин до эфира |
| Отклик | CDN отдаёт ≥ 90% ответов. Промахи идут в роль «каталог» по схеме Cache-Aside через Redis. Горизонтальное автомасштабирование добавляет поды. Роль «checkout» не делит с каталогом пул соединений к БД (Bulkhead) |
| Мера отклика | p99 API каталога на origin ≤ 800 мс; p75 времени до первого товара на 3G ≤ 2 с; p99 оформления заказа не растёт больше чем на 20% от фона (NFR-03, NFR-08) |

## QAS-04. Пропускная способность: старт флеш-распродажи

| Поле | Значение |
|---|---|
| Источник стимула | Покупатели на главном экране с таймером обратного отсчёта (арт. 2) |
| Стимул | 20 заказов в секунду в течение 10 минут на ограниченный остаток товаров |
| Артефакт | Роль монолита «checkout», резервирование остатков в PostgreSQL, outbox уведомлений |
| Окружение | Пиковая нагрузка, остаток товара по акции — сотни единиц |
| Отклик | Остаток резервируется атомарно в БД, без кеша. После исчерпания покупатель сразу видит «товар закончился». Уведомления ставятся в очередь и отправляются без блокировки оформления. Автомасштабирование роли «checkout» |
| Мера отклика | ≥ 99,5% запросов на оформление завершаются успехом или корректным «закончился»; 0 продаж сверх остатка; p99 оформления ≤ 2 с без времени партнёра; рост с 3 до 9 подов ≤ 3 мин (NFR-09, NFR-10, NFR-19) |

## QAS-05. RTO/RPO: потеря региона

| Поле | Значение |
|---|---|
| Источник стимула | Облачный провайдер |
| Стимул | Основной регион недоступен целиком дольше 15 минут |
| Артефакт | Вся платформа, кроме страновых ячеек ПДн у локальных провайдеров |
| Окружение | Год 1: во втором регионе только резервные копии и архив журналов БД. С 7-го месяца: warm standby |
| Отклик | Дежурный объявляет аварию по runbook. Год 1: окружение поднимается из Git (IaC) во втором регионе, БД восстанавливается из архива журналов, DNS переключается. С 7-го месяца: асинхронная реплика повышается до основной. Платежи за окно потери досверяются с партнёрами, у которых они — источник истины |
| Мера отклика | Год 1: RTO ≤ 1 ч, RPO ≤ 5 мин. С 7-го месяца: RTO ≤ 15 мин, RPO ≤ 1 мин. Все платежи окна потери восстановлены сверкой за 24 ч (NFR-06, NFR-12) |

## QAS-06. Устойчивость: деградация SMS-шлюза в день массовой рассылки

| Поле | Значение |
|---|---|
| Источник стимула | SMS-шлюз и операторы связи |
| Стимул | Шлюз отвечает за 20 с вместо 1 с, очередь растёт в 15 раз |
| Артефакт | Модуль уведомлений |
| Окружение | День запуска, идёт маркетинговая рассылка по согласиям |
| Отклик | Транзакционные и маркетинговые сообщения в разных очередях и пулах отправщиков (Bulkhead). Маркетинговая очередь приостанавливается автоматически. Транзакционные уходят с Retry и экспоненциальной задержкой. Через 60 с без ответа — fallback на WhatsApp или push |
| Мера отклика | ≥ 99% транзакционных уведомлений принято хотя бы одним каналом за 60 с; 0 потерь за 1 ч (SLI-NTF-01, SLI-NTF-02) |

## QAS-07. Переносимость: смена облачного провайдера

| Поле | Значение |
|---|---|
| Источник стимула | Решение совета директоров или изменение условий провайдера |
| Стимул | Требование перенести платформу к другому провайдеру (AWS, GCP, Azure или on-prem) |
| Артефакт | Манифесты Kubernetes, IaC, образы контейнеров, данные PostgreSQL |
| Окружение | Плановое учение по выходу, раз в год |
| Отклик | Кластер поднимается из Git у второго провайдера, данные переносятся логической репликацией PostgreSQL. Бизнес-модули не меняются: провайдерские сервисы скрыты за адаптерами |
| Мера отклика | ≤ 5 рабочих дней; 0 изменений в бизнес-модулях; простой при переключении ≤ 15 мин (NFR-17, NFR-18) |

## Assumptions

- A-01. Пик первой недели — 50 тыс. одновременных сессий.
- A-19. Один запрос в 5 с на сессию, 90% попаданий в CDN.
- A-20. Пиковый поток флеш-распродажи — 20 заказов/с в течение 10 минут.
