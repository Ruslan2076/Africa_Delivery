# Задание 3. Нефункциональные требования и стратегия доступности

Доступность обоснована экономикой: показано, сколько стоит каждая девятка и почему остановились на 99,99% к Году 2–3. SLO заданы по сервисам, отказы партнёров разобраны в FMEA, кеширование и наблюдаемость описаны с TTL, инвалидацией и связью метрик с SLI.

## Сквозная нумерация

NFR — нефункциональные требования (NFR-01…NFR-07 уточняют Architecture Vision), SLI-CAT/PAY/NTF — индикаторы сервисов, QAS — сценарии атрибутов качества, FM — виды отказа. Новые допущения: A-19…A-22.
