# SLO-контракт: каталог

**Сервис:** модуль каталога (поиск, списки категорий, карточки товара, изображения) · **Владелец:** команда ядра · **Потребители:** покупатели (UC-01, UC-02), модуль заказа · **Окно:** скользящие 30 дней · **Метод бюджета:** по событиям (Occurrences)

Каталог — первый экран после рекламы (арт. 1: «человек услышит рекламу и откроет приложение»). Его SLO выше базового уровня платформы (99,9%), потому что чтение обслуживает CDN с отдачей устаревшего ответа при ошибке ядра ([ADR-002](../adr-002-caching-strategy.md)). Дополнительная девятка здесь почти бесплатна.

## SLI — что и как измеряется

| ID | Индикатор | Хорошее событие | Все события | Где измеряется |
|---|---|---|---|---|
| SLI-CAT-01 | Доступность чтения | Ответ 2xx, 304 или 404 на запрос каталога, карточки или изображения, включая ответы CDN из устаревшего кеша | Все запросы к `/catalog/*`, `/products/*`, `/img/*` | Логи CDN (edge) — то, что видит покупатель |
| SLI-CAT-02 | Задержка origin | Ответ API каталога на origin быстрее 800 мс | Запросы, дошедшие до origin | Метрика `http_server_request_duration_seconds{module="catalog"}` |
| SLI-CAT-03 | Время до первого товара | Первая карточка отрисована быстрее 2 с | Холодные и тёплые запуски приложения на 3G | RUM в мобильном приложении (OpenTelemetry SDK) |

Исключения: запросы ботов и сканеров, отсечённые WAF; запросы с устройств ниже минимальных требований (Android 8) — для SLI-CAT-03.

## SLO — целевые значения

| SLI | Цель | Бюджет ошибок за 30 дней |
|---|---|---|
| SLI-CAT-01 | 99,95% | 21,6 мин эквивалентного простоя, или 1 плохой запрос из 2 000 |
| SLI-CAT-02 | 99% запросов (p99 ≤ 800 мс) | 1% запросов медленнее 800 мс |
| SLI-CAT-03 | 75% запусков (p75 ≤ 2 с) | 25% запусков медленнее 2 с |

```yaml
apiVersion: openslo/v1
kind: SLO
metadata:
  name: catalog-read-availability
spec:
  service: catalog
  indicator:
    metadata: { name: sli-cat-01 }
    spec:
      ratioMetric:
        good:  { metricSource: { type: cdn-logs, spec: { query: 'status=~"2..|304|404"' } } }
        total: { metricSource: { type: cdn-logs, spec: { query: 'path=~"/catalog/.*|/products/.*|/img/.*"' } } }
  timeWindow: [ { duration: 30d, isRolling: true } ]
  budgetingMethod: Occurrences
  objectives: [ { displayName: availability, target: 0.9995 } ]
```

## SLA — что гарантируется бизнесу и что при нарушении

У покупателей нет договора с платформой, поэтому SLA каталога — внутреннее обязательство перед CEO и инвестором (STK-01, STK-04).

| Обязательство | Значение | При нарушении |
|---|---|---|
| Доступность чтения каталога за календарный месяц | ≥ 99,9% (ниже SLO на 0,05 п. п. — буфер на починку) | Отчёт инвестору в течение 2 рабочих дней; разбор без поиска виноватых; заморозка фич каталога до восстановления бюджета |
| Время до первого товара на 3G | p75 ≤ 2,5 с | Приоритет оптимизации изображений и кеша в следующем спринте |

Алерты дежурному: скорость расхода бюджета SLI-CAT-01 в 14,4 раза выше нормы за 1 час (сжигает 2% бюджета) — звонок; в 6 раз за 6 часов — тикет в рабочее время ([observability.md](../observability.md)).
