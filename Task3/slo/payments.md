# SLO-контракт: оплата

**Сервис:** модуль оплаты (инициирование платежа, приём webhook, переключение между партнёрами, выплаты продавцам) · **Владелец:** команда оплаты · **Потребители:** покупатели (UC-04), продавцы (UC-09), модуль заказа · **Окно:** скользящие 30 дней · **Метод бюджета:** по событиям

Отказы партнёров входят в SLI. Если M-Pesa или Flutterwave не ответили и переключение на резервного партнёра не сработало, для покупателя это наш отказ. Отклонение платежа партнёром по бизнес-причине (нет средств, неверный PIN) — хорошее событие: система отработала.

## SLI — что и как измеряется

| ID | Индикатор | Хорошее событие | Все события | Где измеряется |
|---|---|---|---|---|
| SLI-PAY-01 | Доступность оплаты | Попытка оплаты получила финальный ответ (успех или бизнес-отказ) за 30 с | Все попытки оплаты | Метрика `payment_attempts_total{outcome}` в модуле оплаты |
| SLI-PAY-02 | Задержка подтверждения | Заказ перешёл в «оплачен» за 30 с после успешного платежа у партнёра | Все успешные у партнёра платежи | Разница времени webhook / опроса статуса и смены статуса заказа |
| SLI-PAY-03 | Корректность | Операция совпала в ежедневной сверке с партнёром | Все операции за сутки | Отчёт сверки |
| SLI-PAY-04 | Выплата в тот же день | Выплата продавцу отправлена в календарный день подтверждения получения | Все подтверждённые получения | Метрика `seller_payouts_total{same_day}` |

## SLO — целевые значения

| SLI | Цель Года 1 | С 7-го месяца | Бюджет ошибок за 30 дней (Год 1) |
|---|---|---|---|
| SLI-PAY-01 | 99,9% | 99,95% | 43,2 мин эквивалентного простоя, или 1 сбой из 1 000 попыток |
| SLI-PAY-02 | 99% | 99,5% | 1% подтверждений дольше 30 с |
| SLI-PAY-03 | 99,99% | 99,99% | 1 расхождение на 10 000 операций; каждое разбирается |
| SLI-PAY-04 | 99% | 99,5% | 1 выплата из 100 уходит на следующий день |

```yaml
apiVersion: openslo/v1
kind: SLO
metadata:
  name: payments-availability
spec:
  service: payments
  indicator:
    metadata: { name: sli-pay-01 }
    spec:
      ratioMetric:
        good:  { metricSource: { type: prometheus, spec: { query: 'sum(rate(payment_attempts_total{outcome=~"success|declined"}[5m]))' } } }
        total: { metricSource: { type: prometheus, spec: { query: 'sum(rate(payment_attempts_total[5m]))' } } }
  timeWindow: [ { duration: 30d, isRolling: true } ]
  budgetingMethod: Occurrences
  objectives: [ { displayName: availability, target: 0.999 } ]
```

## SLA — что гарантируется и что при нарушении

| Кому | Обязательство | При нарушении |
|---|---|---|
| Бизнес (STK-01, STK-02) | Доступность оплаты за месяц ≥ 99,5% | Отчёт инвестору и CFO с потерянным GMV по модели; заморозка фич оплаты; разбор за 5 рабочих дней |
| Продавцы (STK-10) | Выплата в день подтверждения получения | Задержка больше 1 рабочего дня — возврат комиссии платформы по этому заказу (решение CEO, Q-04) |
| CFO (арт. 6, п. 6) | Стоимость приёма платежей ≤ 2,5% GMV | Пересмотр маршрутизации между партнёрами в течение месяца |

Зависимость от партнёров: доступность оплаты ограничена доступностью партнёров. Их SLA фиксируется в договоре до подписания (R-03). Если у партнёра SLA ниже 99,9%, второй партнёр на этом маршруте обязателен ([fmea.md](../fmea.md), FM-01).
